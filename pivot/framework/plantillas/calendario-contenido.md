# Calendario de contenido

Para qué sirve: estructura de columnas para armar el calendario de publicaciones de un cliente en Google Sheets. Se copia la fila de encabezados a una hoja nueva por mes y se guarda en `Clientes/<Cliente>/04-Produccion`. Ver [../servicios/creacion-contenido.md](../servicios/creacion-contenido.md).

## Columnas (copiar en este orden a la fila 1)

```
Fecha | Día | Hora | Red | Formato | Tema | Objetivo | Texto (copy) | Llamado a la acción | Enlace al diseño en Canva | Estado | Responsable | Aprobado por cliente (fecha) | Programado en Metricool | Notas | Resultado
```

## Qué va en cada columna

| Columna | Qué escribir |
|---|---|
| Fecha / Día / Hora | Cuándo se publica. Metricool sugiere mejores horarios según la cuenta. |
| Red | Instagram, Facebook u otra. |
| Formato | Publicación, carrusel (varias imágenes que se deslizan), reel (video corto vertical) o historia. |
| Tema | De qué trata, en pocas palabras. |
| Objetivo | Para qué sirve: dar a conocer, educar, generar confianza o vender. |
| Texto (copy) | El texto que acompaña la publicación ("copy" es como se le dice al texto publicitario). |
| Llamado a la acción | Lo único que queremos que haga la persona: escribir por WhatsApp, comentar, guardar, comprar. |
| Enlace al diseño en Canva | Enlace a la pieza. |
| Estado | Usar una lista desplegable: Idea / En producción / Para aprobar / Aprobado / Programado / Publicado. |
| Responsable | Quién la produce (sombrero Contenido). |
| Aprobado por cliente (fecha) | Fecha de la aprobación escrita, guardada en `05-Aprobaciones`. |
| Programado en Metricool | Sí / No. |
| Notas | Ajustes pedidos, ronda de cambios en la que va. |
| Resultado | Se llena después: alcance (cuántas personas la vieron), interacciones y comentarios relevantes. |

## Recomendaciones
- Armar el mes completo antes de que empiece, con 1 semana de anticipación (sugerencia, editable).
- Mezclar objetivos: no todo puede ser venta.
- Enviar al cliente para aprobación por semanas o por mes completo, nunca pieza por pieza.
- Frecuencia de publicación según lo cotizado: `[completar]` por semana.
